# 第 1 层手动操作

## 打开与控制方式

点击 **Tools → Build Layer 1 Climber Arenas**，打开 `Assets/Scenes/ClimberTraining.unity`，点击 Play 后再点击 **Game 窗口**取得键盘焦点。

默认手动控制第 0 个场地，其他场地没有手动输入。**F1** 重置所有角色到墙底并切换为 16 场地脚本演示；再次 F1 重置并回到手动。切换不保留半途姿态，防止两种控制器同时写命令。**R** 在当前模式下重置角色，清空抓握请求并恢复努力值。

使用旧 Input Manager（activeInputHandler=0），按键直接读取 KeyCode，不依赖旧 Input Manager 的轴名称。

| 操作 | 含义 |
| --- | --- |
| 1 / 2 / 3（含小键盘） | 左手 / 右手 / 双手 |
| A / D | 选中手的肩部相对目标沿躯干局部 x 左 / 右移动 |
| S / W | 目标沿躯干局部 z 后 / 前移动 |
| Q / E | 目标沿躯干局部 y 下 / 上移动 |
| 滚轮向上 / 向下 | 选中手的努力值增加 / 减少；每格 0.05，范围 [0,1] |
| 空格 | 切换选中手的抓握请求 |
| R | 重置到墙底 |
| F1 | 重置并切换手动 / 脚本模式 |

默认努力值 **0.70**，默认目标移动速度 **0.30 m/s**。设计的保守单手抬升预算约为 0.552，故默认值留有余量；自由手努力值 0.70 对应 28 N 上限，高于单手自重 9.81 N。需要更快够点时可把自由手努力值临时调到 1.00，但不要把速度或力直接加到 Rigidbody。

双手模式不把“一只开、一只关”直接互换：只要有一手请求未开启，空格会同时开启两手请求；两手都已请求时，空格会同时关闭。**支撑时不要误按空格关闭唯一抓住的手，双手抓顶边后也不要把选 3 与按空格混淆。**

## 怎样理解目标移动

按键移动的是**相对肩部、随躯干朝向旋转的目标**，不是直接移动手，也不是移动世界坐标中的角色。

- 自由手：E 抬手、Q 降手，W 朝墙内伸，S 退出横档前缘。
- 已抓住的手不能移动：Q 降低其相对目标，反作用会抬升/撑起躯干；E 相反。
- 已抓住的手按 S，把目标向后移，躯干会相对向前；按 W 则使躯干后退。
- 不按键时保持目标和努力值，身体继续执行原 PD 命令，不会关闭驱动。

目标距离始终限制在肩部 0.15–0.85 m 内，物理臂长上限仍为 0.90 m。不要靠长按某个方向硬顶不可达位置；先调整支撑手，让躯干升到合适高度。

## 一次换手攀爬与翻上平台的操作顺序

先可按 F1 看一次完整脚本示范，再按 F1 回到墙底手动。以下以 HUD 的训练场坐标为参照，短按微调并停下观察；不是要求按固定秒数盲操作。

### 1. 左手抓最低横档

1. 按 R、1，保持努力值 0.70。
2. 用 S 将自由手退出横档前缘；用 E 把手中心抬到约 y=1.18 m。再用 W 朝横档伸入，用 A/D 对准左侧横档。
3. 用 Q 慢慢落到接触位置，参考手中心 **(-0.20, 1.10, -0.18) m**。可以先按一次空格开启请求，身体会等到真实合法接触后才抓住。
4. 确认左手 HUD 为 **GRIPPED**，不能只看 Request ON。

### 2. 右—左—右交替换手

每轮都遵守：**先让新手实际抓住，再关闭旧手请求。**

| 次序 | 伸出的自由手 | 手中心参考接触位置（训练场 m） |
| --- | --- | --- |
| 初始 | 左手 | (-0.20, 1.10, -0.18) |
| 第 1 次换手 | 右手 | (+0.20, 1.35, -0.18) |
| 第 2 次换手 | 左手 | (-0.20, 1.60, -0.18) |
| 第 3 次换手 | 右手 | (+0.20, 1.85, -0.18) |

具体循环：

1. 选中当前支撑手，轻按 Q 抬升躯干，使另一只手够得到下一横档；需要避开墙面时，对已抓手按 W 让躯干稍后退。
2. 选自由手。先 S 退出前缘至 z≈-0.38 m，再 E 抬到目标接触高度上方约 0.08 m。用 A/D 对准对应侧。
3. W 插入到 z≈-0.18 m，再 Q 落到表中的接触高度。停止移动并等待速度下降，开启抓握请求。
4. 新手显示 GRIPPED 后，选旧手并按空格关闭其请求；等冷却结束，再移动它去下一个点。
5. 重复至最高右横档。始终使用实际位置/状态判断，不以按键时长或 Request ON 判定换手成功。

### 3. 左手转到顶部前缘

1. 右手继续抓最高横档；用右手 Q 抬身，保持躯干在平台前侧，不要直接往平台侧面推。
2. 选左手，保持请求关闭。先退出前缘，再 E 抬到 y≈2.18 m，W 伸到顶部前缘，Q 落到 **(-0.30, 2.10, +0.02) m**，开启请求。
3. 确认左手 GRIPPED。

### 4. 右手也抓顶部前缘

1. 选左手，Q 继续把躯干升到约 y=1.7–1.8 m，给自由手留下可达余量。手固定后，PD 可继续产生撑起所需的推力。
2. 选右手，关闭旧横档上的抓握请求。等冷却后，以“退出—抬高—插入—落下”路径移动到 **(+0.30, 2.10, +0.02) m**，重新开启请求。
3. 确认两手都 GRIPPED。

### 5. 双手撑起并移入平台

1. 按 3 只选择双手，**不要再按空格**。
2. 对固定双手轻按 Q，把躯干中心抬高。保持躯干在前缘外侧约 z=-0.48 m；必要时用 W/S 小幅调整前后距离。
3. 躯干中心达到 **y≥2.43 m**、底面已越过平台后，再按 S，使躯干向平台内移动；保持足够高度，不要提前撞平台侧面。
4. 到躯干中心约 **(0,2.45,0.53) m** 时松开方向键，保持双手抓握，等待速度下降。
5. HUD 的目标区域状态变为 true，并持续稳定 0.30 s 后显示 **Arrived: True**。

目标区域为 x∈[-0.40,0.40]、y∈[2.40,2.80]、z∈[0.30,0.90]，且躯干速度 <0.50 m/s。手碰到目标附近不算到达。

## HUD 与拒绝原因

HUD 显示当前模式和控制对象、各手请求/实际抓握、冷却秒数、设置与实际努力值、主动合力占阶段上限比例、臂长、肩部相对目标、训练场中的手位置、躯干高度/位置和目标状态。脚本模式显示身体实际状态，不拿手动缓存冒充脚本命令。

| 原因 | 怎么处理 |
| --- | --- |
| Request OFF | 空格开启请求 |
| NoContact | 让手接触真实顶面/顶边，不要隔空请求 |
| NotTop | 手在侧面/下方；先后退，再抬到顶面上方 |
| TooFast | 松开移动键等待减速 |
| Cooldown | 等待剩余冷却结束 |
| Occupied | 与另一只手保持足够间距 |
| Layer / OtherArena / DynamicDeferred | 当前对象不属于本任务可抓取范围 |
| rearm | 抓握断裂后，空格先关请求，再按一次开启；不会自动反复吸回 |

相机只改变自身位姿，通过身体状态跟踪第 0 个角色，并把整面墙、两手和顶部平台一起纳入视野。左侧为 HUD，右侧为相机画面。
