# Layer 3：冻结评估集的可行性审计（参考上限，不用于筛选）

【数据】为有测量支持的结论；【推断】为未直接测量的判断，并注明如何验证。用户决定（2026-11-10）：对冻结评估集的每个结构，报告脚本控制器能否完成、几何可行性检查是否通过。审计只作为参考上限，不得用来过滤训练或评估结构。

## 1. 方法

- **几何可行性检查**：`BoxStackFeasibility.Check`，推导见[LAYER3_GENERATOR_V2.md](LAYER3_GENERATOR_V2.md) §2。
  - 要求存在一条从出生位置出发的站立链：每一级都能放下带容差的躯干足迹，并且从上一个站立位置的肩部够得着下一级的边缘。
  - 同时v1的粗可达检查也要通过。
- **脚本控制器**：`BoxStackScriptController`。
  - 它把`BoxClimbSmokeController`的"Seek → Press → Release"流程参数化：每一级的顶面高度、前沿、横向中心和站位深度都取自结构，不再是两个写死的布局。
  - 在训练两级台阶和单箱上，它退化为完全相同的数值。回归测试`GeneralizedControllerClimbsSmokeLayouts`中，两种布局各4个场地，8/8完成。
  - 路线：有可行站立链时沿该链；没有时，按高度依次爬所有非侧塔箱体。
  - 每个结构1次，最长60s模拟时间，只使用公开身体接口。
- **范围**：
  - 对照：训练两级台阶、单Tall箱；
  - v1零样本集63个（`structures/zero-shot-v1`）；
  - v2评估集180个（`structures/box-stacks-v2/eval`）。
- 测试`FeasibilityAudit.AuditFrozenEvaluationSets`，标记`[Explicit]`，需要设置`CLIMB_RUN_DIAGNOSTICS=1`才会运行。数据：[audit.csv](data/feasibility-audit/audit.csv)（245行）。

| 集合 | 难度 | 结构数 | 几何可行 | 脚本控制器完成 | 两者都通过 | 脚本完成但几何判为不可行 |
|---|---|---|---|---|---|---|
| 对照 | 两级台阶、单Tall箱 | 2 | 2 | 2 | 2 | 0 |
| v1零样本 | Easy | 3 | 3 | 3 | 3 | 0 |
| v1零样本 | Standard | 30 | 0 | 0 | 0 | 0 |
| v1零样本 | Hard | 30 | 0 | **16** | 0 | **16** |
| v2评估 | Easy | 60 | 60 | 41（68%） | 41 | 0 |
| v2评估 | Standard | 60 | 60 | 49（82%） | 49 | 0 |

- v2的180个结构全部几何可行，这与生成器的硬约束一致。
- v2上脚本控制器的失败（【数据】，按特征分组的完成数/结构数）：

## 3. 解读

1. **几何检查是保守的，不是严格上限。**
   - 【数据】在v1 Hard上，脚本控制器完成了16个几何判为不可行的结构，它们的踏面是0.15–0.30m。
   - 【推断】躯干的X、Z旋转被锁定，部分搭在窄踏面上时不会倾倒，靠双手和部分支撑就能过渡到上一级。
   - 0.451m的约束来自任务对"站稳"的定义：5条射线覆盖整个足迹，登层统计和进展奖励都依赖这个定义。它不是物理上能否通过的界限。
   - 后果：用几何检查作为成功率的分母，会把一些其实能爬上去的结构排除在外。在v2评估集上没有影响，因为180个全部通过。
   - 验证方法：对v1 Hard的这16个结构，检查脚本控制器过渡时是否触发过`TrySupport`；预期不会触发。
2. **脚本控制器不是策略上限的可靠估计。**
   - 【数据】它在v2上完成67–82%，失败集中在"0.5m矮层 + 横向偏移"的结构。【推断】原因是它的手位固定在箱体中心±0.30m，没有针对偏移调整。
   - 相反，有约1m竖直面的结构它反而几乎都能完成（38/40），因为单Tall箱的流程本来就是为这种情况调好的。
   - 所以"脚本完成"只能证明这个结构可解（存在解），"脚本失败"不说明不可解。
3. **本审计没有过滤任何结构**：v2评估集和训练池保持冻结时的样子。

## 4. 对第3层完成标准的含义

- 完成标准规定"成功率只在通过几何可行性检查的结构上计算"（[LAYER3_DESIGN.md](LAYER3_DESIGN.md) §16）。
  - 在v2评估集上，分母就是全部180个结构。
  - v2 Easy评估集不含单箱结构（单箱全部留给训练，见[LAYER3_GENERATOR_V2.md](LAYER3_GENERATOR_V2.md) §4.1）。
  - 如果以后改用别的评估集，应同时报告几何检查的假阴性率，即上面v1 Hard的现象。第4层玩家搭建的结构必须报告未通过几何检查的比例（[LAYER4_DESIGN_NOTES.md](LAYER4_DESIGN_NOTES.md) §1）。
- 脚本控制器的完成率（Easy 68%、Standard 82%、Hard 67%）可以作为一个参考水平，但不是策略必须超过的上限。
