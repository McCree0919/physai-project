## 2. 判定标准与结论

| 标准（事先约定） | 结果 | 结论 |
|---|---|---|
| 从S1b起点的一级登层率明显超过零动作基线（0.5%） | 【数据】本轮hold为0/200（示范初始化实验时为1/200）。2.5M：s2026为100%，s2027为61.5%；5M：96%和100% | **达到**：两个seed在2.5M和5M都远高于基线 |
| 从S3起点出现二级登层 | 【数据】hold和random均为0/200。s2026：2.5M为0，5M为84.5%；s2027：2.5M为31.5%，5M为100% | **达到**：两个seed都出现，且不是零星个例 |
| 从地面起点的确定性一级/二级/成功（5M） | 【数据】s2026：95.0% / 88.0% / 87.5%；s2027：100% / 100% / 100% | 示范初始化实验和此前incremental在5M时全部为0；本轮两个seed都能从地面完成全程 |

**总结**：只加这一项奖励，端到端策略在两个seed上都从地面学会了完整的两级攀爬。【数据】示范初始化实验（同样的出生分布、同样的状态库）在所有起点、所有checkpoint中二级和成功都为0。

## 4. 分析

1. **两个技能缺口都被打通了。**
   - 【数据】示范初始化实验中：S1b→一级为0–6%，S3→二级为0。
   - 【数据】本轮5M时：S1b→一级为96%/100%，S3→二级为84.5%/100%；hold和random在这两项上均为0。
   - 【推断】高度奖励在"撑起"和"转换"两段提供了与动作相关的连续梯度，而原来只有+0.1和+1的稀疏信号。
   - 但两个seed是同时学会全部阶段的，这个实验无法区分是哪一段先受益。
2. **高度奖励不是白送的。**
   - 【数据】hold从S1b出发能拿到约0.073的高度奖励（§14.2），但一级为0/200。
   - 【数据】训练期RewardHeight从0.01–0.04升到0.16–0.17（上限0.2），与登层率、成功率一起上升。
   - 【推断】没有出现"只刷高度、不登层"的情况。
3. **没有观察到瞬时峰值风险。** §14.2担心策略会把躯干甩高后坠落。
   - 【数据】5M评估中，Fall + OutOfBounds为s2026 3/1000、s2027 0/1000。
   - 【数据】唯一比较多的是s2027 2.5M的S3：Fall 15/200，出现在学会转换之前。
4. **seed差异大、学习时间点不同。**
   - 【数据】s2027在2.5–4M窗口训练期成功率就达到68.9%。
   - 【数据】s2026在2.5–4M窗口训练期成功率只有0.05%，4M之后才明显上升；5M时训练期最后20个摘要的成功率为0.426，仍在上升。
   - 【数据】s2026 2.5M的地面一级率为100%，到5M降为95%：学会二级的同时，一级稍有回落。
   - 【推断】s2026的5M checkpoint还处在快速变化阶段，再训练一段很可能接近s2027。验证方法：从s2026的5M继续训练1–2M步，并按同一协议评估。
5. **s2026 5M从示范起点反而不如从地面起点。**
   - 【数据】成功率：地面87.5%；S1a 48%、S1b 20%、S2 36%；S3 81.5%。
   - 【推断】策略从地面出发时走的是自己的路线，专家快照把它放进不熟悉的中间状态，从那里继续的能力还没学全。
   - 【推断】s2027 5M在所有起点都是100%，说明这只是训练程度问题，不是方法本身的限制。
   - 验证方法：比较s2026地面成功回合与专家轨迹在S1b附近的手位、躯干位置分布。
6. **结果的适用范围。**
   - 【数据】训练和评估都只用同一个两级箱子结构（以及同一个状态库）。确定性评估中，200回合之间的差别只来自出生时的随机扰动。
   - 【推断】200/200不代表对其他结构或更大扰动的鲁棒性。本轮没有测试泛化，这不在单变量消融的范围内。
7. **基线的小差异。**
   - 【数据】本轮hold在S1b的一级为0/200，示范初始化实验时为1/200；S2的一级为97.5%，当时为97%。
   - 【推断】基线不依赖奖励。差异来自运行之间的仿真或采样差别，量级在1/200左右，不影响结论；未进一步查证。

  - 【推断】分层设计（[LAYER3_HIERARCHICAL_DESIGN.md](LAYER3_HIERARCHICAL_DESIGN.md)）的主要价值转向多结构泛化，而不是"单结构能否学会"。
