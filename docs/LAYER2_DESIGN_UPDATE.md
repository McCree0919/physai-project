# 第2层补充设计与实现调整

本次决定已统一写入[LAYER2_DESIGN.md](LAYER2_DESIGN.md)，替代先前的20物体限制、脚本成功格白名单和仅掉落/超时规则。

## 实现检查

1. 原实现没有在线脚本试爬过滤，但离线成功格白名单仍限制了生成分布，确实需要调整。已删除该白名单。Easy现在覆盖h=0.20–0.30、s=0.20–0.80；其他预设高度带不变，横距均0.20–0.80。GenerateAt接受h=0.15–1.00、s=0.20–0.80范围内的连续值；数值范围是当前几何规格，不代表物理可解边界。
2. 生成只检查合法输入、相邻顶面宽松两臂跨度上界（1.80 m）、静态稳定/重叠与出生/目标中心净空。无脚本、轨迹规划、成功标签或基于失败的重采样。粗检查不是完整可解性证明，允许脚本解决不了的结构进入分布。
3. Generate/Load默认不创建控制器。显式scripted=true是可选演示/诊断功能，其规范路线检查仅防止错误附加硬编码脚本，不用于训练结构准入。回归中的脚本测试仅保留Easy基准及其保存场景；取消对其他难度脚本成功的要求，策略本身不改。
4. JSON物体数校验从20改为32；材质数限制独立，未随物体数扩大。测试覆盖32个物体接受、33个拒绝。
5. 动态箱子首轮10–30 kg、每种预设质量固定。默认倾倒只诊断；角色掉落、抓握断裂后无法恢复、物体越界或超时失败，仅保结构专项将倾倒设为失败。当前没有动态箱子或任务失败管理器，因此这两项只更新设计，不提前添加代码；恢复时限和越界范围在对应任务中配置。

## 回归方法

关闭Unity编辑器后执行 `.\scripts\test_layer2.ps1`。它运行原第1层测试和本轮静态测试；保存/加载依旧必须通过物理与粗几何校验，不依赖脚本输出。新增反例取自旧扫描0%成功格(0.25,0.20)、(0.20,0.20)，并检查连续参数(0.237,0.413)可生成、保存验证通过且加载不附加脚本。保留旧扫描原始数据与历史验收记录。

物理检查补充：h=0.15 m时末横档与厚0.20 m的顶部平台发生重叠，因此该参数会因几何穿插被拒绝；Easy预设从0.20 m起采样。此拒绝不参考脚本结果；回归测试单独验证其overlap原因。扫描原始数据保持不变。
