# 第 1 层专项核查：自由手抖动与翻上平台

日期：2026-11-09。仅增强测试采样、断言和报告，没有为通过核查修改身体、力学、目标区域或脚本攀爬行为。身体/抓握/脚本独立版本经 batchmode 验证：编译零错误，PlayMode **12/12 通过**，Unity 退出码 0。

## 1. 自由手悬空保持 5 秒

夹具：左手抓住静态横档、肩部距离连接承重，右手悬空，右手目标保持肩部相对 (0,0.35,0) m、努力值 1.00。右手没有抓握或环境接触。躯干与自由手均为动态刚体，场景并非把它们设为 Kinematic。先稳定 3 秒，再每个物理步采样一次，步长 0.02 s，共 250 个样本、5 秒。

每次采样均打印：左手、右手和躯干的 Rigidbody.IsSleeping；三个刚体相对采样起点的位移；右手相对肩部的位移；右手 PD 命令力。位移以毫米保留四位小数，力以 N 保留六位小数。

| 检查 | 结果 |
| --- | --- |
| 左手休眠样本 | **0/250**，全部 False |
| 右手休眠样本 | **0/250**，全部 False |
| 躯干休眠样本 | **0/250**，全部 False |
| 自由手训练场位移峰峰值 (x,y,z) | **(0.0000,0.0000,0.0000) mm** |
| 自由手相对肩部位移峰峰值 (x,y,z) | **(0.0000,0.0000,0.0000) mm** |
| 自由手 PD 力分量峰峰值 (x,y,z) | **(0.000000,0.000014,0.000000) N** |
| PD 力模长最小 / 最大 | **9.809994 / 9.810008 N** |
| PD 力模长峰峰值 | **0.000014 N**（约 14 μN） |
| 支撑臂峰值约束负载 | **237.4279 N** |

本次原条件重测没有休眠样本，可以排除“重测的零位移仅由刚体休眠造成”。无需运行强制唤醒分支。测试已加入保护：以后只要任一刚体在采样中休眠，就标记该阶段无效，并仅在测试内设置 sleepThreshold=0、每步 WakeUp，重新测满 5 秒，结束后恢复阈值；不修改生产组件或 ProjectSettings。

0.0000 mm 表示浮点位置样本与所用精度下未分辨到变化，不是无限精度的绝对零抖动。该夹具位于约 100 m 平移处，float 位置分辨率也是限制；PD 力仍有微小变化，因此位移打印为零不等于驱动被关闭。

逐样本证据：`results/layer1-jitter-audit.csv`；完整输出在 `results/layer1-body-audit-tests.log` 的 `LAYER1_JITTER_SAMPLE`、`LAYER1_JITTER_SUMMARY` 段。

## 2. 单独的双手撑起、越过边缘测试

顶部平台顶面为训练场局部 **y=2.00 m**，前缘为 **z=0**，平台内部沿 +z。目标区域仍为躯干中心区域：

- 中心 **(0,2.60,0.60) m**，尺寸 **(0.80,0.40,0.60) m**。
- 相对顶面/前缘：中心高于表面 **0.60 m**、向内 **0.60 m**。
- 范围 x∈[-0.40,0.40]，高于表面 **0.40–0.80 m**，向平台内 **0.30–0.90 m**。
- 躯干中心在区域内且速度 <0.50 m/s，连续 0.30 s 才到达；不是手接触触发。

独立测试从躯干 (0,1.50,-0.40) m、双手分别固定在顶部前缘 (-0.30,2.10,0.02) 和 (+0.30,2.10,0.02) m 开始。测试全过程逐步断言两手保持抓握。

| 事件 | 实测 |
| --- | --- |
| 第一次几何进入区域 | **t=1.32 s** |
| 此时躯干中心 | **(0.000000,2.449862,0.313240) m** |
| 此时中心高于平台表面 | **449.862 mm** |
| 此时躯干包围盒最低 y | **2.049862 m**，底面高于表面 **49.862 mm** |
| 此时躯干包围盒最后侧 z | **0.138237 m**，已越过前缘 **138.237 mm** |
| 稳定到达时中心 | **(0.000000,2.446687,0.525841) m** |
| 稳定到达时速度 | **0.000715 m/s** |

测试明确拒绝“最高横档附近”的躯干位置 (0,1.75,-0.18)，也拒绝“高度足够但仍在平台外侧”的位置 (0,2.50,-0.01)。生产判定要求中心至少在前缘内 0.30 m；本次实际轨迹还验证了整个躯干包围盒已越过边缘且底面高于顶面，不能用只升高、不向内移动来通过。

### 双手努力值与主动力

脚本对两手请求的努力值均为 **0.70**。身体现有渐变使实际值从 **0.1333** 上升到 **0.7000**，不是第一步就满输出。

| 指标 | 左手 | 右手 |
| --- | ---: | ---: |
| 实际努力值范围 | 0.1333–0.7000 | 0.1333–0.7000 |
| 整段主动力模长范围 | 5.4032–113.5658 N | 5.4032–113.5658 N |
| 首次进入区域时努力值 | 0.7000 | 0.7000 |
| 首次进入时手部主动力 (x,y,z) N | (0,-48.3773,-1.4885) | (0,-48.3773,-1.4885) |
| 到达时努力值 | 0.7000 | 0.7000 |
| 到达时手部主动力 (x,y,z) N | (0,-48.9965,-3.2304) | (0,-48.9965,-3.2304) |

这是作用于手的主动力；其对躯干的反作用方向相反，负 y 分量对应向上撑身。0.70 时每臂主动合力上限为 **315 N**，本次峰值 113.5658 N 低于上限。这里没有把被动约束负载混作肌肉力。

逐步证据：`results/layer1-body-audit-tests.log` 中的 `LAYER1_PRESS_SAMPLE`、`LAYER1_PRESS_FIRST_ENTRY`、`LAYER1_PRESS_SUMMARY`；NUnit 结果为 `results/layer1-body-audit-tests.xml`。
